# tactile-mp3-phone-remote
A wired ESP32-S3 phone attachment with physical buttons for the next and previous track. [replicates the layout of an MP3 but on phone]


thumbnail concept: [will be added soon]

goal features:
- two map-able tactile buttons
- buttons allow for next/prev track traversal
- bluetooth connection
- app driver which allows you to toggle button purpose
- has a custom handgrip/ phone attachment case

hardware [for the initial iteration]:
- ESP32-S3 dev board
- 2 tactile buttons
- breadboard
- usb-c cable
- (these are sourced from an electronics kit with many bits).
